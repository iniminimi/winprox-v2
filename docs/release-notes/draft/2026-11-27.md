# 27 november 2026

Status: concept

## Nieuw

- Een beheerder zet aanmelden met de telefoon aan of uit bij de organisatie. De computer toont dan een code die de telefoon bevestigt, en alleen een beheerder geeft een gsm vrij zodat iemand een nieuwe kan registreren.

## Opgelost

- Aanmelden met e-mail loopt niet meer vast zolang aanmelden via de telefoon uit staat.

## Verbeterd

- Een nieuw wachtwoord moet langer zijn en mag niet uit een bekend lek komen. Een aanmelding stopt na een lange werkdag, en een beheerder ziet op het beginscherm wanneer een aanmelding ongewoon is.
- Op Platformgebruikers kunt u ook het wachtwoord van een superuser wijzigen.
