# Bijlage verwerkersovereenkomst — Trace

Concept. Dit is een bijlage bij de bestaande verwerkersovereenkomst, geen tweede overeenkomst.

| Onderwerp | Afspraak |
|---|---|
| Rol | De klant bepaalt het doel en de parameters. WinProx verwerkt op die instructie. |
| Foto's | Staan versleuteld op de kaart in het toestel. Ze gaan niet vanzelf naar WinProx. |
| Sleutel | WinProx bewaart de sleutel. Een aangemelde beheerder van de klant kan hem gebruiken. Elk gebruik wordt bijgehouden. |
| Opvragen | Een beheerder vraagt een foto op en geeft een reden. De aanvraag en de reden worden bijgehouden. Alleen een bevoegde beheerder ziet die foto. |
| Bewaartermijn | De klant legt vast hoe lang een opgevraagde foto blijft. WinProx wist de kaart in het toestel niet. |
| Wissen van de sleutel | Daarna is de kaart onleesbaar. |
| Doel | WinProx bepaalt het doel van de klant niet en geeft een foto alleen vrij op zijn instructie. |
